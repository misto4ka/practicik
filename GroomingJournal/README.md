# Журнал записей груминг-салона

Учебный проект: приложение на C# (Windows Forms, .NET 10) + база данных Microsoft SQL Server.

## Как запустить

1. Откройте `GroomingJournal.csproj` в Visual Studio и нажмите F5. NuGet сам скачает пакет `Microsoft.Data.SqlClient` (нужен интернет).
2. Нужен установленный **SQL Server LocalDB**. Проверка: Win+R → `cmd` → команда `sqllocaldb info`. Если выводится `MSSQLLocalDB`, всё есть. Если нет, в Visual Studio Installer добавьте рабочую нагрузку «Хранение и обработка данных».
3. Имя сервера задаётся одной строкой в `Database.cs`: `private const string ServerName = ...`. По умолчанию там `.\SQLEXPRESS`. Если у вас LocalDB из Visual Studio, впишите `(localdb)\MSSQLLocalDB`. Если свой SQL Server, впишите имя из окна подключения в SSMS (например, `localhost` или `ИМЯ-ПК\SQLEXPRESS`). Если вход в SSMS по логину и паролю, а не через Windows, замените в обеих строках подключения `Integrated Security=True` на `User Id=sa;Password=ваш_пароль`.

Если база недоступна, программа при запуске покажет понятное сообщение с причинами.

Как это работает в коде: метод `Database.Initialize()` проверяет через `DB_ID('GroomingSalon')`, есть ли база. Если нет, читает `Database.sql`, делит текст по строкам `GO` на части и выполняет каждую командой `ExecuteNonQuery()`.

## Что умеет программа

- Показывает журнал: дата, день недели, время, кличка, животное, порода, хозяин, телефон, услуга, цена.
- Добавляет новую запись. Если клиент (по телефону) или животное уже есть в базе, используются существующие, иначе создаются новые. Вид животного можно выбрать из списка или вписать новый.
- Не даёт записать двух животных на одно время.
- Удаляет выбранную запись: красная кнопка «Удалить запись» или клавиша Delete (перед удалением спрашивает подтверждение).
- Минимальное оформление: светлый фон, тёмная шапка таблицы, чередующиеся строки, цветные плоские кнопки (метод `StyleButton`).
- Фильтр «только за дату» и итог: сколько записей и на какую сумму.

## Структура базы данных

Пять таблиц:

```
AnimalTypes            Clients                Services
-----------            -------                --------
Id (PK)  <──┐          Id (PK)  <──┐          Id (PK)  <──┐
Name        │          FullName    │          Name        │
            │          Phone       │          Price       │
            │                      │                      │
            │          Pets        │          Appointments│
            │          ----        │          ------------│
            │          Id (PK)  <──┼───┐      Id (PK)     │
            └───────── AnimalTypeId│   │      PetId (FK) ─┘ (на Pets)
                       ClientId ───┘   └───── ServiceId (FK) (на Services)
                       Name, Breed            AppointmentDate, AppointmentTime
```

PK — первичный ключ (уникальный номер строки), FK — внешний ключ (ссылка на строку другой таблицы).

| Таблица | Назначение | Связи |
|---|---|---|
| `AnimalTypes` | Справочник видов: собака, кошка... | Один вид → много животных |
| `Clients` | Хозяева: ФИО, телефон | Один клиент → много животных |
| `Pets` | Животные: кличка, порода | Ссылается на `Clients` и `AnimalTypes` |
| `Services` | Прайс-лист: услуга и цена | Одна услуга → много записей |
| `Appointments` | Журнал: дата, время | Ссылается на `Pets` и `Services` |

**Почему так много таблиц?** Это нормализация: каждый факт хранится один раз. Телефон хозяина записан в одном месте, а не в каждой записи. Цена услуги меняется в одной строке `Services`. Одному хозяину можно привязать несколько животных.

**Ограничения в таблицах**, их можно назвать преподавателю:
- `PRIMARY KEY` и `IDENTITY(1,1)` — уникальный номер, который растёт автоматически.
- `FOREIGN KEY` — нельзя сослаться на несуществующего клиента, животное, услугу.
- `UNIQUE` на `Clients.Phone` — один телефон = один клиент.
- `UNIQUE (AppointmentDate, AppointmentTime)` — на одно время одна запись. Это защита на уровне самой базы, а программа дополнительно проверяет заранее и показывает понятное сообщение.
- `CHECK (Price >= 0)` — цена не может быть отрицательной.
- `NOT NULL` — поле обязательно к заполнению.

**Типы данных:** `NVARCHAR` — текст с поддержкой русских букв (`N'...'` в скрипте значит юникод), `DECIMAL(10,2)` — деньги, `DATE` — дата, `TIME(0)` — время без долей секунды.

**День недели в базе не хранится**, он вычисляется из даты в программе (`a.Date.DayOfWeek`). Хранить его отдельно не нужно, иначе данные могут разойтись.

## Разбор ключевых мест кода

**`private const string ConnectionString = ...` (Database.cs)**
Строка подключения: сервер `(localdb)\MSSQLLocalDB`, база `GroomingSalon`, вход через учётную запись Windows (`Integrated Security=True`).

**`using var conn = OpenConnection();`**
Открывает соединение. Слово `using` закрывает его автоматически в конце метода, даже если произошла ошибка.

**`cmd.Parameters.Add("@date", SqlDbType.Date).Value = ...`**
Параметризованные запросы. Значения не вклеиваются в текст SQL, а передаются отдельно. Это защита от SQL-инъекций и от проблем с кавычками (например, кличка `О'Брайен`).

**`ExecuteNonQuery()` / `ExecuteScalar()` / `ExecuteReader()`**
- `ExecuteNonQuery` — команда без результата (INSERT, DELETE).
- `ExecuteScalar` — одно значение (например, `COUNT(*)` или `Id`).
- `ExecuteReader` — таблица результатов, читается циклом `while (reader.Read())`.

**`JOIN` в `GetAppointments`**
В записи хранятся только номера. Цепочка `JOIN` собирает строку журнала: запись → животное → клиент и вид, запись → услуга.

**Транзакция в `AddAppointment`**
При добавлении записи создаются до четырёх строк в разных таблицах (клиент, вид, животное, запись). `BeginTransaction` / `Commit` / `Rollback` гарантируют: либо сохраняется всё, либо при ошибке ничего. Не получится клиент без записи или наполовину созданные данные.

**`GetOrCreateClient` (и аналоги для вида и животного)**
Шаблон «найти или создать»: сначала `SELECT Id ...`; если нашли, используем; если нет, делаем `INSERT ... OUTPUT INSERTED.Id`, который сразу возвращает номер новой строки.

**`DateTime?` (nullable)**
Параметр `date` может быть датой или `null`. Если `null`, показываем все записи, если дата, то только за этот день.

**`TimeSpan`**
Тип SQL `TIME` в C# соответствует `TimeSpan`.

**Конструктор `MainForm()`**
Выполняется при создании окна: строит интерфейс, загружает услуги и виды животных, заполняет таблицу.

**`chkFilter.CheckedChanged += (s, e) => RefreshGrid();`**
Подписка на событие. Лямбда `(s, e) => ...` — короткая запись метода: «когда галочка изменилась, обнови таблицу».

**`Dock = DockStyle.Fill / Top`**
Элемент «прижимается» к краю окна или занимает всё свободное место, поэтому окно можно растягивать.

**`grid.Rows[index].Tag = a.Id;`**
`Tag` — скрытое поле строки. В нём лежит Id записи, чтобы при удалении знать, какую строку удалять из базы.

**`ToString()` в классе `Service`**
Выпадающий список показывает текст из `ToString()`: «Стрижка — 1500 ₽», а внутри лежит целый объект с Id.

**`ru.DateTimeFormat.GetDayName(...)`**
Возвращает день недели по-русски. `ru` — это `CultureInfo("ru-RU")`.

**Валидация в `BtnAdd_Click`**
Перед записью проверяем, что поля не пустые, выбрана услуга, время не занято. Если проверка не пройдена, показываем `MessageBox` и выходим через `return`. Ошибки базы ловим через `try / catch`, чтобы программа не вылетала.

# Практикум по C#

## 📋 Описание

Проект представляет собой интерактивный практикум, где каждое задание реализовано как отдельный класс с описанием, требованиями и решением. Пользователь может выбрать уровень, затем конкретное задание, прочитать его описание и запустить решение.

Практикум состоит из **50 заданий**, разбитых на **3 уровня сложности**. Задания покрывают основы языка, ООП, коллекции, LINQ, исключения, файлы и JSON, асинхронность и Git.

## 🚀 Инструкция по запуску

### Требования

- .NET 6.0 или выше
- Visual Studio 2022

### Шаги запуска

1. **Клонировать репозиторий**

`ash
git clone https://github.com
cd practicik
`

2. **Открыть решение**

- Visual Studio: открыть `CSharpPracticum.sln`

3. **Запустить приложение**

`ash
cd CSharpPracticum
dotnet run
`

4. **Навигация по меню**

- Введите номер уровня (1–3) для выбора группы заданий
- Введите номер задания для его запуска
- Введите `0` или `q` для выхода

### Тесты (задание 45)

Юнит-тесты библиотеки лежат в папке `LibraryTests` (xUnit):

`ash
cd LibraryTests
dotnet test
`

## 📝 Заметки по уровням

### Уровень 1

Основы языка: вывод и ввод в консоль, примитивные типы, ветвления и `switch`, циклы, массивы и матрицы, строки, `Dictionary`, работа с датами, базовый Git (репозиторий, ветки, merge, конфликт).

### Уровень 2

Методы расширения, `StringBuilder`, `TryParse`, собственные коллекции и обобщения, ООП (наследование, интерфейсы, паттерны «Стратегия» и «Фабрика»), `IComparable` / `IComparer`, `Equals` / `GetHashCode`, собственные исключения, `IDisposable`, LINQ, продвинутый Git.

- Перегрузку `Sum(int[])` нельзя объявить рядом с `Sum(params int[])`: у них одинаковая сигнатура, поэтому перегрузка принимает `IEnumerable<int>`.
- Без `GetHashCode`, согласованного с `Equals`, `HashSet` не отбрасывает дубликаты.

### Уровень 3

Дубликаты и мемоизация, бенчмарки коллекций, `yield return`, `async/await`, `Task.WhenAll`, `CancellationToken`, порядок `catch`, мини-проекты (Todo List с JSON, Библиотека с юнит-тестами) и продвинутый Git (`stash`, `rebase -i`, теги, `reflog`, `bisect`).

- `LinkedList` выигрывает на вставке в середину только рядом с уже найденным узлом, а доступ по индексу у него медленнее, чем у `List`.
- `Task.WhenAll` выполняет задачи одновременно, поэтому время равно самой долгой задаче, а не сумме.

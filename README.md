# C# & Git Practicum (Задания 1–50)

Учебный практикум по основам C#, ООП, LINQ, асинхронному программированию и продвинутой работе с Git.

## Запуск проекта
1. Откройте решение `CSharpPracticum.sln` в Visual Studio 2022 (или выше).
2. Запустите проект (`F5` или `Ctrl + F5`).
3. В консольном меню выберите нужный уровень сложности и номер задания.

## Документация по Git
Все сценарии, выводы терминала и логи по Git-заданиям (**15, 35, 46–50**) собраны в отдельном файле: [git-notes.md](./git-notes.md).
